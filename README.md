# iPAS AI 應用規劃師模擬考

可在瀏覽器使用的初級與中級練習系統。題目為依 [115 年度官方簡章](https://www.ipas.org.tw/api/proxy/uploads/certification/AIAP/115%E5%B9%B4%E5%BA%A6AI%E6%87%89%E7%94%A8%E8%A6%8F%E5%8A%83%E5%B8%AB%E8%83%BD%E5%8A%9B%E9%91%91%E5%AE%9A%E7%B0%A1%E7%AB%A0%28%E5%88%9D%E3%80%81%E4%B8%AD%E7%B4%9A%29_20251225235744.pdf)評鑑範圍編寫的原創模擬題，並非官方考古題。

## 開始使用

需要 Node.js 22.13 或更新版本。在專案目錄執行：

```powershell
npm start
```

接著開啟 <http://127.0.0.1:8765/>。此專案不需安裝套件，使用 Node.js 內建 SQLite。請使用 `npm start` 啟動，純靜態 HTTP 伺服器已無法保存成績。

如需讓同一網路內的其他電腦使用，在伺服器上執行：

```powershell
$env:HOST = '0.0.0.0'
npm start
```

其他電腦請開啟 `http://伺服器IP:8765/`。各裝置**必須連到同一台伺服器**，才會共用成績。若要變更連接埠，可設定 `PORT` 環境變數。

## 功能

- 初級綜合、中級數據分析、中級機器學習三種模擬考路線。
- 五科共 400 題練習題；每場從兩個科目各抽 25 題，避開同一知識點的重複問法，並隨機排列題目與選項。
- 每場 50 題、90 分鐘。可跳題、修改答案、中途重新開啟或跨裝置續考；時間到自動交卷。
- 開始前必填姓名，可選填識別碼以區分同名考生。
- 交卷後提供分數、錯題解析及常錯主題。
- 成績紀錄與成績曲線可依考生和考試類別篩選，並可匯出 CSV。

## 資料保存

測驗與紀錄保存在伺服器的 `data/ipas-ai.sqlite`，伺服器重啟後仍會保留。資料庫檔案已加入 `.gitignore`；搬遷伺服器時，先停止服務，再複製資料庫檔案。可將 `DB_PATH` 環境變數設為其他持久化磁碟的絕對路徑。建議定期在停止服務後備份資料庫，亦可在「成績紀錄」匯出 CSV。

舊版保存在瀏覽器 `localStorage` 的測驗紀錄，首次使用新版網站時會自動匯入 SQLite。其他裝置若也有舊紀錄，需在該裝置開啟新版網站一次，才會匯入。

此版本以姓名加選填識別碼查找考生和未完成測驗，沒有帳號驗證。請在可信任網路使用；若要公開到網際網路，應先加上登入及權限控管。同名考生建議填寫不同識別碼。

初級官方單科測驗時間是 **75 分鐘**；本系統依需求統一設定為 **90 分鐘模擬考**。
